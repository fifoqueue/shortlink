# UI 검증 범위

검증 환경: 실행 중인 `localhost:5174`, 로그인된 관리자 세션, 1280px와 390px 너비. 실제 운영 설정의 저장, 권한 부여, 계정·그룹 삭제는 실행하지 않았다.

| 화면                                                         | 확인한 내용                                                                                             |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| 홈                                                           | 추가 설정의 5개 탭, 방향키 전환, 한 패널만 표시, 다른 탭의 입력값 유지, 모바일 줄바꿈                   |
| 계정                                                         | 공통 로고, 데스크톱 탐색/설정 카드, 모바일 한 열 배치, 보안 확인창, 삭제 확인창의 취소·Escape·초점 복귀 |
| 이용 약관·개인정보 처리방침                                  | 공통 헤더·로고·언어 선택·계정 메뉴와 계정 페이지 이동                                                   |
| 관리자 사이트·링크/API·보안·테마·플러그인·링크 관리          | 페이지 로딩, 입력 구조, 현재 메뉴 표시, 모바일 문서 가로 넘침                                           |
| 기본 확장·CAPTCHA·OIDC·권한 관리·속도 제한·Enhanced Tracking | 설정 필드, 공통 shadcn 입력/버튼/카드, 모바일 배치                                                      |
| 권한 그룹·사용자 편집                                        | 하위 페이지 로딩, 그룹 탭/자동 할당 탭, 방향키, 탭 전환 후 폼 필드 유지                                 |
| 그룹 사용자 추가                                             | 사용자 검색, 추가창 열기, 취소 후 닫힘, 원래 추가 버튼으로 초점 복귀                                    |
| 그룹 삭제 확인                                               | 확인창 열기, 취소 후 닫힘, 원래 삭제 버튼으로 초점 복귀                                                 |
| 테마 미리보기                                                | 저장하지 않고 mono 프리셋의 라이트/다크 배경·버튼 색 변경, 새로고침 후 기존 설정 복원                   |

클릭 API의 성공 여부만으로 판정하지 않는다. 확인창은 DOM에서 사라지는 것을 기다린 후 초점을 확인하고, 탭은 선택 상태와 보이는 패널 수 및 기존 필드의 유지 여부를 확인한다. 화면 저장 동작과 인증 수단 변경은 별도 테스트 계정/데이터에서 검증해야 한다.

## 적용 기술

이 저장소는 SvelteKit을 유지하며 shadcn-svelte 컴포넌트 소스를 `src/lib/components/ui`에 보관한다. shadcn-svelte는 shadcn/ui의 **비공식 커뮤니티 Svelte 포트**다. React 원본을 설치했다고 표현하지 않는다. Tailwind CSS는 두 구현의 스타일 기반이다.

- [shadcn/ui 공식 설치: Tailwind CSS](https://ui.shadcn.com/docs/installation/manual)
- [shadcn-svelte 소개 및 포트 관계](https://www.shadcn-svelte.com/docs)
- [화면 구조와 회귀 검사 기준](ui-design.md)

## 코드·데이터 검증

코드 변경 후 `yarn lint`, `yarn check`를 순서대로 실행한다. 번들링 변경에는 `yarn build`도 실행한다. 보안·트랜잭션 검증은 [데이터 일관성 문서](data-consistency.md)의 독립 검사와 전용 PostgreSQL 테스트 DB를 사용한다.
