# 성능 검증

2026-09-22, Node.js 24, 로컬 Docker PostgreSQL, 연결 풀 10개. 각 항목을 세 번 실행한 중앙값이다. 변경 전후 별도의 새 테스트 DB에서 같은 데이터 구조와 같은 스크립트를 사용했다. 앱 시작·스키마 초기화·테스트 데이터 준비 시간은 제외했다.

| 작업                        |    변경 전 |   변경 후 | SQL 수 전/후 |
| --------------------------- | ---------: | --------: | -----------: |
| 설정 조회 100회             |  130.01 ms | 127.08 ms |    100 / 100 |
| 권한 조회 30회              |  619.89 ms |  35.79 ms |     180 / 30 |
| 클릭 접수 100건 (동시 10건) |  196.33 ms | 153.24 ms |    500 / 400 |
| 클릭 큐 소비 300건          | 1880.55 ms | 107.85 ms |    2478 / 21 |

권한 시나리오는 그룹 40개·사용자 50명·멤버십 2,000개에서 익명 요청을 평가한다. 클릭 시나리오는 링크 10개를 사용하며 외부 메타데이터 플러그인·Redis·ClickHouse는 비활성화했다. 위 수치는 함수 단위 측정이며 운영 HTTP 지연이나 처리량을 보장하지 않는다. 설정 단독 조회의 시간 차이는 작다.

## 적용한 변경

- 권한 조회는 매칭되는 활성 그룹만 단일 SQL 스냅샷으로 읽는다. 만료·회원 사유 우선순위·즉시 권한 회수를 유지한다.
- 화면에서 이미 읽은 `locals.settings`를 재사용하고, 별도 설정 조회도 필요한 두 필드만 읽는다.
- 클릭 접수는 조건부 UPDATE로 한도 검사와 증가를 함께 처리한다. 추적을 끈 경우 이 단일 SQL 자체가 원자적 변경이다. 추적을 켜면 큐 삽입과 같은 트랜잭션으로 커밋한다.
- 큐 소비는 기본 250건씩 일괄 INSERT·최종 클릭 시각 갱신·DELETE를 커밋한다. 메타데이터는 잠금 전에 기본 16개씩 동시 수집한다. 잠긴 부모 링크는 이번 순회에서 제외해 뒤쪽 링크를 처리하며, 실패한 배치는 개별 이벤트로 나누어 정상 이벤트를 처리한다.
- 비밀번호 연산은 같은 scrypt 설정과 저장 형식을 유지한 비동기 작업이다. 신규 해시 계산은 가능한 경로에서 전역 쓰기 잠금 전에 끝낸다. 같은 조건의 네 번 해시 프로브는 동기 194.4ms/타이머 0회, 비동기 59.7ms/타이머 52회였다. 회귀 실행에서도 해시 중 타이머 진행을 확인한다.
- 사용한 인증 challenge/TOTP 기록은 고유 제약을 가진 단일 INSERT로 처리한다. 만료 정리는 요청마다 반복하지 않고 프로세스별 UTC 날짜가 바뀔 때 실행한다.
- 계정·권한 변경의 공유 잠금은 FK 잠금 순서와 최초/마지막 관리자 불변조건 때문에 유지한다. 변경 없는 플러그인 레지스트리 재구성과 트랜잭션 안의 중복 초기화는 생략한다.

## 재현

비어 있는 전용 PostgreSQL 테스트 DB를 준비한다. 운영 `.env`나 개발 서버는 사용하지 않는다.

```bash
TEST_DATABASE_URL=postgres://postgres:password@127.0.0.1:5432/shortlink_perf_test yarn node scripts/check-invariants.mjs --benchmark
```

정확성 검증은 별도의 빈 테스트 DB에서 다음 명령으로 실행한다.

```bash
TEST_DATABASE_URL=postgres://postgres:password@127.0.0.1:5432/shortlink_invariants_test yarn node scripts/check-invariants.mjs
```

이번 검증: `yarn lint`, `yarn check` 통과. 실제 PostgreSQL에서 동시 클릭 한도, 큐 롤백·중복 방지·PK 충돌 보존·잠긴 배치 우회, 권한 조회 조건·즉시 회수, 비밀번호 호환성·이벤트 루프 진행, 기존 계정/설정/마이그레이션 회귀 검증 통과.
