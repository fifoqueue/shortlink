# 화면과 문구

Svelte 5용 shadcn-svelte 컴포넌트는 `src/lib/components/ui`에 둔다. `components.json`은 공식 CLI와 경로를 공유하며, Tailwind 4는 Vite 플러그인으로 처리한다. 기존 폼 action, 플러그인 슬롯, 권한 검사는 그대로 사용한다.

## 구성

- 홈은 링크 입력, 추가 설정, 내 링크 순서다. 추가 설정의 탭은 숨겨진 입력값도 제출할 수 있도록 계속 마운트한다. QR 코드는 요청할 때 연다.
- 로그인 화면은 공통 `AuthCardPage`, 사이트 탐색은 `SiteHeader`, 관리 화면은 `AdminShell`을 사용한다. 계정 화면은 데스크톱에서 왼쪽 탐색과 오른쪽 설정 카드로 나누고, 모바일에서는 위쪽 탐색과 한 열의 카드로 표시한다.
- 삭제 확인은 `AlertDialog`, 일반 확인창은 `Dialog`, 선택 패널은 `Tabs`로 구성한다. 폼마다 인증 토큰 코드를 추가하지 않는다.
- shadcn 색상·모서리는 `styles/ui.css`의 `--ui-*` 토큰을 통해 사이트·관리자 테마에 연결한다. 다크 모드도 배경·카드·본문·보조 텍스트·강조·강조 위 텍스트·테두리 색을 각각 설정한다.

### 테마 저장과 미리보기

`theme.customTokens`는 기존 라이트 색상과 공통 모서리·글꼴 설정을 유지한다. `theme.darkTokens`는 별도의 다크 색상이다. 이 값이 없는 기존 설정은 이전 다크 팔레트를 계산해 사용하므로 기존 사이트의 표시를 유지한다. 설정은 기존 JSON 설정 행에 함께 저장한다.

관리 화면의 **색상 모드**는 실제 사이트의 라이트/다크/시스템 동작을 정한다. **편집할 색상**은 수정할 팔레트를 선택한다. 미리보기는 선택한 팔레트에 실제 사이트와 같은 토큰 변환을 적용한다. 숨겨진 팔레트의 입력값도 함께 제출하므로 팔레트를 오가며 수정해도 값이 사라지지 않는다. 프리셋 변경·초기화는 두 팔레트를 함께 바꾼다.

모서리 `0`은 사각형이며, 버튼·입력창·카드·메뉴에 같은 기준값을 사용한다. 원형 라디오와 QR 이미지 같은 고유한 모양은 유지한다. 글꼴은 브라우저에 설치되거나 사이트에서 로드한 글꼴이어야 한다.

확인창은 가장 가까운 테마 루트로 포털 처리한다. 저장바처럼 `backdrop-filter`가 있는 부모 안에 고정 위치 창을 넣지 않는다. QR 코드의 흰 여백은 이미지에만 적용하며 미리보기 패널과 버튼은 테마를 따른다.

로고·사이트 이름·현재 사용자·관리자 메뉴 접근 여부는 루트 layout의 `shell` 데이터에서 제공한다. 홈, 계정, 법적 문서, 통계, 공유, 초대, API 토큰 화면은 `SiteHeader`를 재사용한다. 페이지별로 로고나 계정 정보를 다시 조합하지 않는다.

## 컴포넌트 회귀 검사

설치된 Bits UI의 상태 속성은 `data-orientation="horizontal"`, `data-state="active"`, `data-state="open"`이다. shadcn 템플릿을 갱신할 때 이 속성과 스타일 선택자가 일치하는지 확인한다. 탭 선택과 확인창 취소 버튼은 폼 안에서도 제출하지 않도록 `type="button"`을 명시한다.

변경 후에는 확인창 취소·Escape·초점 복귀, 탭 클릭·방향키·입력값 유지, 390px/1280px 배치, 라이트/다크 모드, 공개 페이지 사이의 헤더 일치를 실제 브라우저에서 확인한다. 클릭 호출이 성공한 것만으로 동작이 검증됐다고 판단하지 않는다.

## 문구

사용자에게는 입력할 내용, 결과, 다음 행동만 안내한다. 권한 그룹의 적용 과정, 저장소, 세션 구현 같은 내부 설명은 관리자 화면이나 운영 문서에 둔다. 삭제·권한 회수의 영향과 복구 불가 안내는 생략하지 않는다.

공통 문구는 `src/lib/i18n/ui-text.ts`가 제공하는 한국어·영어 사전을 사용한다. 기존 배포 기본 홍보 문구와 정확히 같은 문자열만 새 기본 문구로 정규화하며, 운영자가 따로 작성한 문구는 보존한다.

## 보안 폼과 초기화

서버가 넣는 hidden token에는 `data-shortlink-ssr-token` 표시를 붙인다. `app.html`의 초기 스크립트가 Svelte hydration 전에 이 노드만 제거하고, 공통 `FormSecurityTokenInjector`가 현재 토큰을 다시 주입한다. JavaScript를 끄면 서버가 넣은 토큰이 남아 일반 폼 제출을 지원한다.
